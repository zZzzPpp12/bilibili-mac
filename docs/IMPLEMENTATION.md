# 0.3.0 实现与验证状态

更新：2026-10-29。macOS 开发预览。本文区分模拟写入、真实只读检查与账号本人验收。

## 本轮视频互动

| 功能 | 当前行为 | 验证范围 |
| --- | --- | --- |
| 点赞/取消赞 | 读取关系后发送明确 like/unlike，成功回执后更新，防重复点击 | 端点、CSRF、请求准备、成功/拒绝/未知结果和迟到回执测试 |
| 投币 | 原创最多 2 枚、转载最多 1 枚，检查余额/已投数量/自己投稿，支持附加点赞 | 数量与余额边界、取消/旧确认不提交、最终状态变化重新确认、附加点赞失败测试 |
| 三连 | 单次服务端请求，确认默认收藏夹和最多消耗，分别应用三项回执 | 完成/部分成功/已投满不新增扣币/异常数量、收藏刷新通知、重复提交测试 |
| 结果核对 | 未知或部分结果先刷新，保留已知状态，暂离后返回仍待核对 | 刷新失败不放行、账号切换清空上下文、旧响应不恢复状态测试 |
| 打包 | 0.3.0 / build 4，临时签名，真实 Bundle 启动检查 | 见下方构建与窗口记录 |

投币和三连均需应用内确认；最终提交前重新读取同一账号、同一稿件的余额和关系。状态变化时不发送 POST，更新页面并要求重新确认。已经完成三项时禁止重复三连。若本次回执 coin=false，不按 multiply 字段再次扣减余额。

必要浏览标识由官方 finger/spi 返回，只保存在当前会话内存，重新登录会清除。认证 POST 使用七条端点允许列表、CSRF、官方视频 Referer，不跟随重定向。风险/验证错误提供官方视频链接，由本人处理后刷新，不自动补发互动或处理验证。

## 自动测试

环境：Apple silicon、macOS 26.6.1、Xcode 26.6（17F113）、macOS SDK 26.5、Swift 6.3.3。

```sh
BILIMAC_LIVE_TEST=1 BILIMAC_LIVE_PLAYBACK=1 bash Scripts/test.sh
bash Scripts/build-app.sh
```

完整测试共 62 项：此前 40 项，加上 8 项视频互动 API 与 14 项互动状态/并发测试。62 项全执行通过；默认 CI 跳过 3 项真实联网检查，执行其余 59 项。

新增重点：登录/CSRF/稿件校验、官方标识获取与清除、点赞与取消赞参数、1–2 枚数量与转载限制、余额不足/自己投稿/已投满、取消与过期确认、最终核对失败不提交、状态变化重新确认、重复点击一次写入、三连部分成功不补投、旧账号与旧读取结果丢弃、未知结果跨导航保留。

所有互动 POST 被独立 URLProtocol 会话截获，不会到达 B 站。真实只读检查使用全新无凭据客户端，检查热门/详情、二维码、官方浏览标识、评论排序/游标/楼中楼与真实视频的媒体时钟/画面尺寸。没有在测试中读取 Keychain、点赞、投币、三连或发布内容。
