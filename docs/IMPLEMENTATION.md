更新：2026-10-29。当前为 macOS 开发预览；本页区分自动测试、真实只读检查与账号本人验收。

## 本轮实现

| 功能 | 当前行为 | 已验证范围 |
| --- | --- | --- |
| 我的收藏 | 账号收藏夹、公开/私密标识、切夹、服务端分页、失效视频占位 | 响应字段、分页重试、切夹及账号隔离测试；游客窗口检查 |
| 收藏编辑 | 多选草稿、增删差集、无变化不请求、新建公开/私密夹 | 表单/CSRF、中文与特殊字符编码、重复保存及未知结果测试 |
| 稍后再看 | 完整账号列表、播放页加入/移出、列表确认移除 | 请求端点、成功回执、重复点击、失败核对与换号测试；游客窗口检查 |
| 只读评论 | 最热/最新、游标分页、置顶去重、楼中楼、刷新/分页失败保留正文 | 模拟接口与状态测试；真实游客接口；原生窗口的排序、更多及楼中楼展开 |
| 播放暂停 | 起播后用户立即暂停时，30 秒检查不误报起播失败 | 完整播放测试；窗口中暂停并回到 0 秒，超过 30 秒未误报 |
| 打包 | 0.2.0 / build 3，临时签名、真实应用启动自检 | Release 构建、codesign、--check-startup 通过 |

收藏和稍后再看只操作当前扫码账号。状态只存在内存中，不持久化私密收藏列表。写操作遇到网络中断或不完整回执后，先读取核对，再允许继续；不会自动重试 POST。新建收藏夹立即写入账号，取消勾选窗口不会撤销创建，界面已明确说明。

评论本轮为文字浏览：显示用户名、正文、日期、地区（接口提供时）和点赞数；表情显示文字，纯图片等内容显示占位。没有发布评论、点赞或图片预览入口。稍后再看接口一次返回最多 100 条，客户端没有虚构分页。

## 自动测试与真实只读检查

环境：Apple silicon、macOS 26.6.1、Xcode 26.6（17F113）、macOS SDK 26.5、Swift 6.3.3。

```sh
BILIMAC_LIVE_TEST=1 BILIMAC_LIVE_PLAYBACK=1 bash Scripts/test.sh
bash Scripts/build-app.sh
```

40 项测试全部执行通过：8 项核心逻辑、3 项既有网络、4 项启动、3 项播放集成、7 项资料库/评论 API、12 项资料库/评论状态与并发、3 项真实只读检查。默认 CI 跳过 3 项真实联网检查，其余 37 项执行。

新增回归重点：收藏只在保存时提交差集；新建夹不自动收藏视频；重复点击只发一次写入；未知结果必须先成功读取；刷新失败保留正文和游标；分页重试原页；相同 opaque cursor 返回新评论时可继续；账号、夹、排序变化后的迟到响应不得覆盖当前页面；楼中楼独立重试且不被普通主评论分页作废。

真实检查使用新建的无凭据客户端，读取热门/详情/评论最热与最新、下一页及楼中楼，并生成网页二维码；真实 AVPlayer 检查媒体时钟前进和解码画面尺寸。模拟 POST 使用 URLProtocol，不会到达 B 站。没有在测试中读取 Keychain、修改真实收藏、投币或发布内容。

受限环境最初阻止两个播放测试监听本机端口；允许回环监听后完整执行通过。真实接口检查只代表当时网络与样本，不保证服务长期可用。所有 UI 状态不能仅由编译通过推断。

## 原生窗口检查

已实际打开 0.2.0 打包应用，确认新增侧栏入口、收藏/稍后再看的游客扫码引导、播放页两个账号操作入口、真实评论正文。已切换最新评论、加载更多并展开真实楼中楼。另在最终构建中暂停视频并将进度归零，超过 30 秒仍保留画面且没有误报起播失败。视频测试结束后保持暂停。

尚未代用户完成扫码，也未自动操作用户真实收藏或稍后再看。登录后的私密权限、真实多夹增删、新建夹和服务器回执仍需要账号本人验收。自动测试通过不等同于这些真实账号操作已验收。
