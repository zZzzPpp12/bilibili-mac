## 本次自动测试

测试环境：Apple silicon、macOS 26.6.1、Xcode 26.6（17F113）、macOS SDK 26.5、Swift 6.3.3。

最终执行：

```sh
BILIMAC_LIVE_TEST=1 BILIMAC_LIVE_PLAYBACK=1 bash Scripts/test.sh
bash Scripts/build-app.sh
```

16 项测试全部通过：8 项核心逻辑、3 项模拟网络/二维码域名、3 项播放集成、2 项显式开启的真实只读检查。默认执行跳过 2 项真实接口测试，其余 14 项执行。测试没有读取真实账号凭据、发布内容、投币或发消息。

播放集成使用两份合成 MP4 生成本机 HLS，验证完整四段播放列表，再让真实 AVPlayer 播放并检查时间前进与画面尺寸。真实游客播放同样检查媒体时间与画面尺寸，而非仅检查播放器 ready 状态。

真实二维码响应使用 `account.bilibili.com` 扫码域名，已经加入精确允许列表；同时保留旧 `passport.bilibili.com`，回归测试拒绝相似的第三方域名。没有记录生成的二维码密钥。

最初受限执行环境禁止本机端口监听，两个集成测试因此失败；允许本机网络后通过。这是运行环境限制。原生界面检查服务两次超时，因此本次没有完成截图或逐项 UI 操作验收，不能由编译和媒体集成测试推断所有布局/交互都已验证。

## 已知限制

- 需要 macOS 26+；当前仅在 Apple silicon 上本地构建。没有提供公证、自动更新和商店安装。
- 首次扫码确认、登录恢复/退出、会员画质和账户权限需用户实际验收。
- 真实接口检查是当时网络的一个样本，不保证接口长期可用；搜索/推荐/弹幕有实现，但尚未逐项完成联网 UI 验收。
- 高密度弹幕排轨在主线程，尚未做帧率、长时间内存与功耗基准；mode 7/8/9 暂不支持。
- 画质/分 P/小窗的快速交叉操作、全屏与键盘焦点需进一步原生 UI 回归。
- 不含参考项目的持续磁盘预读、自适应连接数、离线下载和复杂 CDN 补传增强。
- 收藏、评论、投币、下载、私信和 iOS 属于 PRD 后续阶段，未用空按钮模拟实现。
